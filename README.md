# QuantMind.AI official website

Static single-page site (no build step).

- `index.html` – the whole site (EN default, 中文 toggle)
- `img/` – images used by the page
- `vercel.json` – caching and security headers

Deploy: push to GitHub; Vercel (Framework preset: Other) redeploys automatically.
Log in links point to https://app.quantmindnevo.ai/login?login=1
